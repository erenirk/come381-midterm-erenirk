# Otel Rezervasyon Sistemi

Bu projede otellerin oda ve rezervasyon bilgilerini tutan bir veritabanı tasarladım. Sistemde oteller, odalar, oda tipleri, müşteriler ve rezervasyonlar bulunuyor. Bir müşteri birden fazla rezervasyon yapabildiği için müşteri ile oda arasındaki çoktan çoğa ilişkiyi rezervasyon tablosuyla kurdum. Verilerin tutarlı kalması için tablolar arasında primary key ve foreign key ilişkileri kullandım.
